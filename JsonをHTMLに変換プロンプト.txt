# code_artifact.htmlの改善
1. 全体
- style のため classを設定し、bootstrapを用いる
- 条（article）、項(paragraph)、号(item)には 属性 id を設定する


2. 表示変更
- 項の番号(paragraph_no) が1の場合は表示しない
- 号の番号(item_no) は、漢数字のみとして「第一号」なら「一」のみ表示する
- フォントが小さいので16pxに



# code_artifact.htmlの不要な文字や行の削除

1. 先頭のヘッダ部
- 「章・節・条・項・号の個別装飾・ブックマーク対応」を削除

2. 左サイドメニュー
- 「目次ナビゲーション 97条」から"97条"を削除

3. 規約本体部

- 1行目（管理規約）：行削除
- 3行目（9 章・・）：行削除

# JSONデータ変換ミス
"section_number": "第２節","article_number": "第25条","paragraph_no": 1 のオブジェクト items[2] が { "item_no": "三", "各棟修繕積立金": "各棟修繕積立金" } となっています。これは、{ "item_no": "三", "text": "各棟修繕積立金" } となるべきものですが、他にもこのような変換ミスがないか確認してください。

# code_artifact.htmlの表示方法の変更
code_artifact.htmlのcssとscript部分を分割し、それぞれcss, js フォルダに配置していますので注意してください。
- 条のタイトルと第1項
	- 条のタイトルは、条の上段に配置
	- 第１項のみは、条番号の横に全角１文字空けて配置
【例】
（article_title）0
article_number　paragraphs[0]のtext

- 節
	- 「第〇節」の文字色を黒にする
- sub_item
	- sub_item_no 前後の"（"と"）" を削除
	- sub_item_no の文字色を黒にする
